# بقالة العزي للمواد الغذائية

تطبيق Android Native مستقل لإدارة عمليات البقالة والمبيعات والمشتريات والمخزون والحسابات.

## هوية المشروع

- الاسم: بقالة العزي للمواد الغذائية — Al Azzi Grocery Management
- المستودع: https://github.com/saleh12340/The-latest-grocery-store-management-app
- الفرع: `main`
- Android namespace / applicationId: `com.saleh.alazzi.grocery`
- الحد الأدنى: Android 8.0 (API 26)
- compileSdk / targetSdk: 36
- Java / Kotlin JVM toolchain: 17

## التقنيات

- Kotlin وJetpack Compose وMaterial 3
- MVVM وViewModel وCoroutines وStateFlow/Flow
- Room وSQLite
- Navigation Compose
- Android Bluetooth APIs وESC/POS Raster
- Android Canvas/Bitmap لتوليد الإيصالات
- Android Sharesheet وFileProvider لتصدير ومشاركة الملفات

## الوظائف الموجودة حالياً

- إعداد حساب مدير وتسجيل دخول PIN مع تخزين مشتق آمن للـ PIN.
- إدارة العملاء والموردين وعرض كشوف الحركات.
- إدارة الأصناف والكميات والأسعار وتسويات المخزون مع سجل حركة.
- إنشاء فواتير البيع والشراء وحفظ تفاصيلها ضمن معاملات قاعدة بيانات.
- تحديث أرصدة العملاء والموردين والصندوق والمخزون عند ترحيل الفواتير.
- مفاتيح idempotency لمنع تكرار آثار العمليات المالية والمخزنية.
- سجل فواتير المبيعات والمشتريات مع شاشة تفاصيل الأصناف.
- مرتجعات بيع وشراء جزئية مرتبطة بالفاتورة الأصلية، مع منع تجاوز الكميات المتبقية.
- مصروفات وحوالات وملاحظات.
- ملخصات يومية للمبيعات والمشتريات والربح الإجمالي التقديري، وملخص الصندوق والديون والمخزون.
- استعراض طابعات Bluetooth المقترنة، اختيار عرض 58/80mm، وإرسال إيصال اختبار ESC/POS.
- توليد الإيصالات بصيغة Bitmap وتصدير الفواتير ومشاركة الملفات.
- نسخ احتياطي واستعادة عبر مدير النسخ الاحتياطي.

## البناء والتحقق

المتطلبات: JDK 17 وAndroid SDK 36.

من جذر المستودع:

```bash
./gradlew testDebugUnitTest
./gradlew compileDebugAndroidTestKotlin
./gradlew assembleDebug
```

يعمل GitHub Actions تلقائياً عند الدفع إلى `main`، وينفذ اختبارات الوحدة، ويتحقق من ترجمة اختبارات Android، ثم يبني APK ويحسب SHA-256 ويرفع ملف البناء كـ Artifact لمدة 14 يوماً.

رابط إجراءات البناء:
https://github.com/saleh12340/The-latest-grocery-store-management-app/actions

**تنبيه الاختبارات:** خطوة `compileDebugAndroidTestKotlin` تتحقق من ترجمة اختبارات Android فقط؛ لا تعني تشغيلها على محاكي أو جهاز فعلي. يجب تنفيذ اختبارات Bluetooth والطباعة الفعلية على طابعة متوافقة.

## الأعمال التي ما زالت تحتاج استكمالاً

هذا المشروع قيد التطوير، ولا يُعلن اكتماله التجاري قبل استكمال واختبار ما يلي:

- تقارير مالية ومخزنية شاملة مع فلاتر فترات زمنية، وتكلفة بضاعة مباعة وصافي ربح بعد المرتجعات والمصروفات.
- استكمال إعدادات المتجر والطابعة والنسخ الاحتياطي وإدارة التصنيفات والوحدات.
- مراجعة صلاحيات المدير والكاشير على مستوى كل إجراء ومستودع البيانات.
- استكمال اختبارات قاعدة البيانات وواجهات المستخدم على محاكي، واختبارات الترحيل والاستعادة.
- اختبار الطباعة العربية و58mm/80mm والمشاركة على أجهزة فعلية وطابعات مختلفة.
- مراجعة دورة حياة نماذج الفواتير وحفظ حالتها عند الدوران وإعادة إنشاء الشاشة.
- مراجعة تجربة الاستخدام على الشاشات الصغيرة والكبيرة وإتاحة الوصول.

## قواعد سلامة البيانات

- لا تستخدم WebView أو LocalStorage.
- لا تستخدم destructive migrations.
- استخدم معاملات Room لكل العمليات المالية والمخزنية المترابطة.
- لا تحذف السجلات المالية التاريخية عند الإلغاء؛ يجب تسجيل الأثر العكسي.
- لا تعتبر نجاح CI دليلاً على اختبار جهاز أو طابعة فعلية.
- لا تضع أسراراً أو بيانات حساسة في المستودع.
